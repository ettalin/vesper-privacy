# Vesper — privacy policy

The published privacy policy for [Vesper](https://github.com/ettalin/vesper), a
private time-tracking Chrome extension.

Live at **https://ettalin.github.io/vesper-privacy/**

This repository is public because the Chrome Web Store requires the privacy
policy to be reachable by anyone, including its reviewers. It contains only this
page — no extension code.

Every change to the policy is visible in this repository's history, which is what
the "Changes to this policy" section refers to.
